I’ve *taught myself*[^1] to write software across multiple languages and domains.

More recently I have been building anything that piques my interest: [an lsp](https://github.com/voidKandy/knowls), [a blockchain experiment](https://github.com/voidKandy/llm_chain) and others you can see on this site. I'm currently building a [game engine](https://github.com/voidKandy/zig_render) to learn the lower level details of rendering and game systems.
